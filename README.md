# Open Meadow sample demo

This is the **sample-data demo** for Open Meadow by HarborNestDigital. It is ready for GitHub Pages: upload these files at the repository root and enable Pages from the root of your chosen branch. All asset paths are relative, so a repository subpath works.

Visitors can edit records locally in their own browser. The visible sample banner and **Customize → Reset sample data** restore the demonstration records. No buyer records or account credentials are included. The separate customer ZIP starts clean.

Data is stored in browser IndexedDB on each visitor's device. GitHub Pages serves static files; it is not a shared database or an automatic sync service. HTTPS enables the offline asset cache and installable browser-app behavior where the browser supports it.
