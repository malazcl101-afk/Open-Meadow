Welcome to Open Meadow.

A gentle home for lesson plans, attendance, grades, reading, goals, and the memories of learning together.

Open your planner →
1

Open it

Unzip the download first. Keep index.html, app.js, style.css, the icons, and the manifest in the same folder. Double-click index.html on your computer. Use a current Chrome, Edge, Firefox, or Safari browser in a regular window.

Bookmark the same file or hosted URL for next time. If local file storage is blocked by your browser, put the folder on a trusted HTTPS host and open that URL.

2

Set up your family

Students→Subjects→Lessons→Attendance

Give each learner a profile and add the subjects you teach. Create lessons in the daily, weekly, or monthly view. Enter earned and possible points on a lesson or separate assessment when it is graded; scores appear in Gradebook automatically. Assignments can show priority and in-app past due labels. Record attendance and minutes for each learner. The dashboard, Progress, Records, and Reports update from those entries.

3

Make it yours

Go to Customize for your homeschool name, school year and planning targets. Set grade weights for Practice, Quiz, and Test to a total of 100%. Choose from five light themes or pick your own accent color. You can change font, spacing, card style, contrast, and display currency. Restore default appearance resets only appearance choices.

Currency changes the symbol and formatting; it does not convert amounts you already entered.

4

Back up your records

In Customize → Backup & records, click Download JSON backup. Save the file somewhere you can find it, ideally on another drive or cloud storage you control. To move devices, open Open Meadow in the destination browser and select Restore backup. This replaces the destination planner after confirmation, so back up its existing records first.

You can also export a lessons CSV for spreadsheet review. Reports offer printable report cards, attendance logs, progress summaries, and unofficial transcript summaries. Add a saved teacher comment in Reports. Review all records before sharing.

Phone, tablet & home screen

The interface adapts to small screens. For dependable phone use, upload the customer folder to an HTTPS website you control and open that URL. On iPhone/iPad Safari, use Share → Add to Home Screen. On Android Chrome, use the browser menu → Install app or Add to Home screen where offered. Keep the website URL and browser profile consistent; an installed home-screen copy can have separate storage in some browsers. Export a backup before switching how you open it.

After the hosted app has loaded, its service worker caches the application files for offline reopening on supported browsers. Records remain local. Local file:// opening may not support installation or offline caching, and some browser settings block local storage.

Your data stays with you

No login, subscription, or automatic sync. Records are stored in IndexedDB in this browser profile on this device. Another device, browser, private window, or installed app storage area can show a separate empty planner. Clearing browser/site data may erase your local records. Download a JSON backup regularly.

Open Meadow does not upload your entries to HarborNestDigital. Links you add to resources or portfolio can open outside websites; the planner itself does not store linked files.

Where to find things

  • Lessons & Calendar: dated plans, scores, and attendance marks.
  • Students, Attendance, Gradebook: profiles, hours, weighted grades and assessment results.
  • Curriculum, Reading, Goals: progress and records.
  • Family & School year: events, appointments, breaks, holidays, daily routines and optional how-the-day-felt check-ins.
  • Assessments & Assignments: tests, priorities and past due labels.
  • Projects & Enrichment: named milestones, achievements, trips, life skills and a portfolio with optional image/PDF attachments up to 2 MB each. Attachments are included in JSON backups.
  • Records: daily, weekly and annual hours plus a checklist you define from local rules. It does not decide compliance.
  • Budget, Reports, Library: spending, printable summaries, notes and links.
  • Search: find records across the planner.

If something seems wrong

My records look empty

Check that you opened the same file or website in the same browser profile. Do not clear browser data. Restore your most recent JSON backup if you have one.

Backup will not import

Use an unedited Open Meadow JSON backup. It replaces all current records after confirmation. A CSV export is for spreadsheets and cannot be restored as a full backup.

Download or print does not start

Allow downloads or pop-ups for the site and try a regular browser window. For printing, use the browser print dialog and choose Save as PDF if desired.

Install option is missing

Open the planner from HTTPS in Safari or Chrome; local files do not qualify for browser installation. Browser menus and availability vary by version.
